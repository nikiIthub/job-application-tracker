## Job Application Tracker
A simple and responsive web application to track your job application.

## Features
Add job applications,
Edit applicatons,
Delete applications,
Search by company,role and location,
Filtered jobs by application status,
search and status filter work together,
Data persist by local storage,
Responsive Design.

## Technologies use
HTML5
CSS3
JavaScript
Dom manipulation
LocalStorage

## project structure
index.html - Application structure
style.css - Style and responsive design
script.js- Application logic and localStorage

## How to use
1. Enter company name
2. Enter job role
3. Enter job location
4. Select application status
5. Click **Add job**
6. Use **Edit** & **Delete** to manage Applications
7. Use sesrchbox and status filer to find Applicatons
